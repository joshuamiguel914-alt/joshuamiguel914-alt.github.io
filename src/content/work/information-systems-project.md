## Problem

Establishing a professional, centralized digital presence to showcase accounting information systems capabilities, technical skills, and practical project portfolios to prospective employers and clients without relying solely on static traditional resumes.

## My Role

Full-Stack Web Developer and Content Designer. I planned, designed, and deployed a responsive personal portfolio website to present case studies, professional credentials, and technical stacks in an interactive, accessible layout.

## Process

1. Architecture & Wireframing: Outlined system requirements, website navigation structure, and page component hierarchy (Hero, About, Project Case Studies, Skills, and Contact Form).
2. Database & Backend Configuration: Set up local server environments to handle dynamic content, form handling, and data management.
3. Frontend Development & Styling: Wrote clean semantic markup and responsive CSS stylesheets to optimize visual layout across both desktop and mobile viewports.
4. Testing & Deployment: Executed local host testing for layout responsiveness, cross-browser compatibility, and seamless navigation flow.

## Tools Used

HTML, CSS, PHP, SQL, phpMyAdmin, XAMPP (Local Host Deployment), Visual Studio Code, and GitHub.

## Result and What I Learned

Successfully built and deployed a fully functional, structured web portfolio that dynamically highlights accounting systems expertise, technical competencies, and project case studies.

Deepened practical mastery of backend-to-frontend integration using PHP and SQL via phpMyAdmin. I learned the importance of responsive design patterns and modular layout structuring, ensuring that complex project details remain scannable and user-friendly across all device screens.
